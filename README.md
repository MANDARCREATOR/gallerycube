## 🚀 Why Gallery Cube?

Windows Photos notoriously refuses to open iPhone `.heic` and camera `.raw` files without purchasing or installing extra codec packages from the Microsoft Store. Online conversion websites upload your personal family photos to third-party cloud servers and have restrictive file limits.

**Gallery Cube solves this completely:**
- **Zero Paid Codecs Required**: Works straight out of the box on Windows 10 and Windows 11.
- **100% Local & Private**: All decoding and conversions happen locally on your CPU/GPU. Zero cloud uploads, zero telemetry.
- **Ultra-Fast C++ SIMD Decoding**: View 48MP/200MP photos and 60 FPS 4K video clips without stuttering or memory leaks.
- **1-Click Bulk Converter**: Convert entire folders of `.heic` or `.raw` images to universal `.jpg`, `.png`, or `.webp` while keeping all EXIF date stamps and GPS coordinates intact.

## ⚡ First-Run Double-Click Setup

The very first time you launch **Gallery Cube**, a setup window will appear:
1. Select **"All Photos & Videos"** (or choose *"Photos Only"*).
2. Click **"🚀 Apply & Set as Default Double-Click Viewer"**.
3. Windows will immediately associate all selected formats with Gallery Cube. Double-clicking any `.heic`, `.jpg`, `.png`, or `.mp4` file in File Explorer will open it instantly!

## 🛡️ Windows 10 & 11 Installation Note

Because Gallery Cube is an independent indie release, Windows Defender SmartScreen may display a blue *"Windows protected your PC"* screen when running the installer for the first time.

**To run the installer:**
1. Click **"More info"** on the blue SmartScreen prompt.
2. Click **"Run anyway"**.

*(As more users install the software, Microsoft SmartScreen cloud telemetry automatically registers the application and the prompt disappears permanently).*
